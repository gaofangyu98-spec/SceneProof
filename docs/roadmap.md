# 开发路线图

## 阶段 0：基础工程

- [x] 仓库、打包、代码检查、类型检查、测试和持续集成
- [x] 接入真实 FFprobe
- [x] 命令行 JSON 和中文可读输出

## 阶段 1：可复现运行记录

- [x] 生成用例清单
- [x] 运行和产物记录
- [x] Mock 提供器
- [x] 本地产物存储
- [ ] 将校验器接入运行流程

## 阶段 2：确定性校验

- [ ] 容器和媒体流检查
- [ ] 缺失音频和时长错误检查
- [ ] 黑帧、冻结帧和静音检测
- [ ] 结构化证据和失败分类

## 阶段 3：质量评估

- 关键帧和字幕提取
- 基于评分量表的多模态评估
- 证据引用
- 人工复核和评审模型校准

## 阶段 4：回归报告

- 基线版本和候选版本对比
- 失败聚类
- Markdown 和 HTML 报告
- 持续集成质量门禁

## 阶段 5：可用产品

- 最小 Web 界面
- 合成演示项目
- 安全检查
- 公开作品集文档
