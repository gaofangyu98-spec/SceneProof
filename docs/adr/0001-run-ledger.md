# ADR 0001：使用不可变运行目录保存生成证据

## 背景

AI 视频生成任务依赖模型版本、输入脚本、随机参数、异步任务和多个中间产物。只保存“任务成功”或一个最终视频，无法支持后续复现、失败定位和版本回归。

## 决策

每次运行创建独立目录：

```text
<case-id>/<run-id>/
  manifest.json
  run.json
  artifacts/
```

- `manifest.json` 是执行时的输入快照。
- `run.json` 记录状态、时间、提供器信息、产物路径、大小、MIME 类型和 SHA-256。
- `artifacts/` 保存本次运行的产物。
- 运行目录创建后不覆盖；重复的运行编号直接失败。
- 提供器只负责生成产物和报告实际模型信息，不负责写入运行记录。

## 原因

- 运行记录可以独立归档、比较和审计。
- 产物哈希可以发现文件被替换或损坏。
- Mock 提供器和真实平台适配器共享同一记录结构。
- 提供器失败时仍然可以保存部分产物和错误信息。

## 后果

- 每次运行会占用额外磁盘空间，后续需要增加清理和保留策略。
- 大体积视频不适合直接提交到 Git，运行数据必须由 `.gitignore` 排除。
- 公开示例只能使用 Mock 或经过授权的合成产物。
